# 👟 Nike Store

A modern and responsive Nike sneakers e-commerce website.

## 🌐 Live Demo

[Visit Nike Store](https://mounibzamma7-debug.github.io/Nike-Store/)

## ✨ Features

- Modern and responsive user interface
- Product catalog
- Product search
- Shopping cart
- Favorites system
- Order management
- Admin dashboard
- Local data storage using LocalStorage

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage
- Font Awesome

## 📁 Project Structure

```text
Nike-Store/
│
├── index.html
├── style.css
├── script.js
├── admin.html
├── admin.css
├── admin.js
├── favicon.svg
└── images/
```

## ⚙️ Run Locally

1. Clone the repository:

```bash
git clone https://github.com/mounibzamma7-debug/Nike-Store.git
```

2. Open the project folder.
3. Launch `index.html` using Live Server in VS Code.
